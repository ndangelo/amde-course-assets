# AMDE Course Assets

A shared library of visual resources for Art + Media + Design courses and Nugget of Joy lessons.

## Organization

- `shared/gestalt/` — Gestalt principles and visual perception diagrams
- `shared/typography/` — typography examples and type-related graphics
- `shared/color/` — color theory, contrast, and palettes
- `shared/accessibility/` — accessibility and usability references
- `shared/design-process/` — research, ideation, composition, and critique resources
- `amde-350-social-design/quote-project/` — Social Change Quote Project visuals
- `amde-350-social-design/social-campaigns/` — social design and campaign references
- `amde-155-web-design/` — introductory web design teaching graphics
- `amde-355-advanced-web/` — advanced web design teaching graphics

## Using images in WordPress

For public images, use a raw GitHub URL:

```html
<img
  src="https://raw.githubusercontent.com/ndangelo/amde-course-assets/main/shared/gestalt/gestalt-laws-infographic.png"
  alt="Infographic explaining six Gestalt principles"
  loading="lazy"
  style="width:100%;max-width:760px;height:auto;"
>
```

Replace the path with the file's actual repository path. Keep descriptive filenames and meaningful alt text. Add source and usage information for third-party work; only upload materials you have permission to redistribute.

## File naming

Use lowercase names, hyphens instead of spaces, and file extensions that reflect the format. Prefer SVG for original vector diagrams and PNG/WebP/JPG for raster images.

## Attribution log

For each third-party image, record its original source URL, creator if known, license or permission status, and the date checked. The repository is an asset organizer, not a substitute for usage rights.
